# CertChain API Documentation

This document outlines the backend API endpoints built with Django REST Framework to handle off-chain metadata, university authentication, and deterministic PDF hashing for the CertChain Soroban smart contract.

**Base URL (Local Development):** `http://localhost:8000/api/`

---

## 1. Authentication Endpoints

### University Login
Authenticates an authorized university and returns JSON Web Tokens (JWT).

* **URL:** `/auth/login/`
* **Method:** `POST`
* **Auth Required:** No
* **Content-Type:** `application/json`

**Request Body:**
```json
{
  "username": "maseno_admin",
  "password": "securepassword123"
}
Success Response (200 OK):

JSON
{
  "refresh": "eyJhbGciOiJIUzI1NiIsInR5c...",
  "access": "eyJhbGciOiJIUzI1NiIsInR5c..."
}
Note: The access token must be included in the Authorization header for protected routes: Authorization: Bearer <your_access_token>.

## 2. Certificate Processing
Process & Hash Certificate
Receives the student's metadata and the PDF certificate. It saves the metadata off-chain, runs the document through the SHA-256 hashing engine, and returns the unique hash to be signed to the blockchain.

URL: /certificates/process/

Method: POST

Auth Required: Yes (JWT)

Content-Type: multipart/form-data (Crucial: Do not send as raw JSON due to the file upload)

Request Payload (Form Data):

student_name (text): "John Doe"

student_id (text): "CS/001/2026"

degree_name (text): "BSc. Computer Science"

graduation_year (number): 2026

pdf_file (file): [Binary PDF File]

Success Response (201 Created):

JSON
{
  "message": "Certificate processed successfully ready for on-chain registry.",
  "document_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
}
Error Response (400 Bad Request - Duplicate):

JSON
{
  "error": "A certificate with this exact hash has already been processed."
}
## 3. Public Verification
Fetch Certificate Metadata
Allows employers or any third party to retrieve the off-chain metadata of a verified certificate using its unique SHA-256 hash.

URL: /certificates/<str:document_hash>/metadata/

Method: GET

Auth Required: No

URL Parameters:

document_hash: The exact 64-character SHA-256 hash generated by the system (and verified via Soroban).

Success Response (200 OK):

JSON
{
  "student_name": "John Doe",
  "student_id": "CS/001/2026",
  "degree_name": "BSc. Computer Science",
  "graduation_year": 2026,
  "university_name": "Maseno University",
  "created_at": "2026-06-05T14:30:00Z"
}
Error Response (404 Not Found):

JSON
{
  "detail": "Not found."
}

# CertChain API Documentation

This document outlines the backend API endpoints built with Django REST Framework to handle off-chain metadata, university authentication, and deterministic PDF hashing for the CertChain Soroban smart contract.

**Base URL (Local Development):**

```text
http://localhost:8000/api/
```
**Base URL:** `https://cert-chain-backend.onrender.com`

---

# 1. Authentication Endpoints

## University Login

Authenticates an authorized university and returns JSON Web Tokens (JWT).

| Property | Value |
|-----------|---------|
| **URL** | `/auth/login/` |
| **Method** | `POST` |
| **Authentication Required** | No |
| **Content-Type** | `application/json` |

* **Endpoint:** `POST /api/auth/login/`

### Request Body

```json
{
  "username": "admin",
  "password": "admin123"
}
```

### Success Response (200 OK)

```json
{
  "refresh": "eyJhbGciOiJIUzI1NiIsInR5c...",
  "access": "eyJhbGciOiJIUzI1NiIsInR5c..."
}
```

> **Note:** The access token must be included in the `Authorization` header when accessing protected routes.

```http
Authorization: Bearer <your_access_token>
```

# 2. Certificate Processing

## Process & Hash Certificate

Receives the student's metadata and PDF certificate, stores metadata off-chain, computes a deterministic SHA-256 hash, and returns the hash that can be signed and registered on-chain.

| Property | Value |
|-----------|---------|
| **URL** | `/certificates/process/` |
| **Method** | `POST` |
| **Authentication Required** | Yes (JWT) |
| **Content-Type** | `multipart/form-data` |

> **Important:** Do not send the request as raw JSON because a PDF file upload is required.

### Request Payload (Form Data)

| Field | Type | Example |
|---------|---------|---------|
| `student_name` | Text | John Doe |
| `student_id` | Text | CS/001/2026 |
| `degree_name` | Text | BSc. Computer Science |
| `graduation_year` | Number | 2026 |
| `pdf_file` | File | Binary PDF File |

### Example Request

```http
POST /api/certificates/process/
Authorization: Bearer <access_token>
Content-Type: multipart/form-data
```

### Success Response (201 Created)

```json
{
  "message": "Certificate processed successfully ready for on-chain registry.",
  "document_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
}
```

### Error Response (400 Bad Request - Duplicate Certificate)

```json
{
  "error": "A certificate with this exact hash has already been processed."
}
```

# 3. Public Verification

## Fetch Certificate Metadata

Allows employers, institutions, or any third party to retrieve off-chain certificate metadata using a verified SHA-256 document hash.

| Property | Value |
|-----------|---------|
| **URL** | `/certificates/<str:document_hash>/metadata/` |
| **Method** | `GET` |
| **Authentication Required** | No |

### URL Parameters

| Parameter | Description |
|------------|-------------|
| `document_hash` | The exact 64-character SHA-256 hash generated by the system and verified via Soroban |

### Example Request

```http
GET /api/certificates/e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855/metadata/
```

### Success Response (200 OK)

```json
{
  "student_name": "John Doe",
  "student_id": "CS/001/2026",
  "degree_name": "BSc. Computer Science",
  "graduation_year": 2026,
  "university_name": "Maseno University",
  "status": "ACTIVE",
  "created_at": "2026-06-05T14:30:00Z"
}
```

### Error Response (404 Not Found)

```json
{
  "detail": "Not found."
}
```

# Authentication Flow

```text
1. University logs in
        ↓
2. Receives JWT Access Token
        ↓
3. Uploads Certificate + Metadata
        ↓
4. Backend Generates SHA-256 Hash
        ↓
5. Hash Returned for Blockchain Registration
        ↓
6. Employer Verifies Using Hash
        ↓
7. Metadata Retrieved from Off-Chain Storage
```


### List Issued Certificates (Students)
Retrieves a list of all students and certificates issued by the authenticated university.

* **Endpoint:** `GET /api/certificates/`
* **Auth Required:** Yes (`Authorization: Bearer <access_token>`)

**Success Response (200 OK):**
```json
[
  {
    "student_name": "Jane Doe",
    "student_id": "CS-2026-002",

    "graduation_year": 2026,
    "university_name": "Maseno University",
    "status": "ACTIVE",
    "created_at": "2026-06-07T10:30:00Z"
  }
]
